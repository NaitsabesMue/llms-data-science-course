What this example simplifies

Each word is treated as one token. All displayed matrices are invented for teaching, not extracted from a trained model. Their coordinates do not literally mean “red”, “toy”, or “robot”. We start with a deliberately simple input matrix, omit positional encoding and normalization, and use one attention head with identity value and output projections. Actual Transformer blocks also include normalization and a feed-forward network; those operations belong between this attention update and the next block. The next block has its own learned matrices.
