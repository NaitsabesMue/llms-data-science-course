# AMU teaching snapshots

Original HTML downloaded from the three official URLs on 21 October 2026 during
lab preparation. These files contain source documents, not model answers. Each
JSON sidecar records the source URL, capture date (day precision) and SHA-256.
Content belongs to the respective AMU sites; preserve source attribution.

The notebook tries the live page first. If a request fails or returns unusable
HTML, it uses this dated copy, reports the failure, and keeps the copy and its
provenance in the student's local cache. Subsequent runs reuse that same copy.
Choose a new local snapshot directory to try collecting fresh pages. A saved
snapshot may differ from current policy; this matters for the web comparison.
